# **N-Bank Task**

![N-Back](https://github.com/ThipkanlayaJaiaue/adaptive-executive-function-tasks/blob/main/Updating-NBack/nBack.gif)

### Task Configuration

The task included three versions:

- **Control:** Participants classified each letter as a consonant or vowel. Fixed trial duration based on familiarisation.
- **Standard:** 2-back task. Equal numbers of match and non-match trials (excluding the first two trials). Fixed trial duration based on familiarisation.
- **Adaptive:** 2-back. Equal numbers of match and non-match trials (excluding the first two trials). Trial duration was initially set based on familiarisation and adjusted for the subsequent trial based on performance on match trials.

**Trial randomisation:** After the first two trials, subsequent trials were presented in random order, subject to the following constraints:

- The same letter could not be presented on consecutive trials.
- Each letter (A, E, I, U, H, K, M, or R) appeared in at least 5% of trials.
- **Standard and adaptive versions:** No more than two consecutive match trials.
